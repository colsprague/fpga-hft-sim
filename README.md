# FPGA HFT Simulation

Simulation-oriented low-latency market data processing pipeline using FPGA-inspired architecture and Python tooling.

## Overview

This project explores how FPGA-style architectures can be used for low-latency market data processing in high-frequency trading systems.

The current focus is on:
- simulated market feed generation
- packet parsing
- order book reconstruction
- latency analysis
- FPGA-compatible pipeline design

## Technologies
- Python
- Verilog
- ModelSim
- Git

## Repository Structure
'''
rtl/      -> FPGA logic
sim/      -> testbenches and simulations
python/   -> modeling and analysis tools
docs/     -> architecture notes
results/  -> latency measurements and outputs
'''

## Goals
- Learn FPGA workflow and verification
- Explore low-latency systems design
- Build realistic market-data simulations
- Analyze throughput and latency tradeoffs
